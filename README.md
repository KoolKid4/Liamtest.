# Batswana Tech Website

This repository contains a simple static website for **BATSWANA TECH (PTY) LTD**, a company that provides office automation and PABX solutions.

## Structure

- `index.html` – main landing page with sections for services, about, and contact.
- `styles.css` – basic styling for the site.

## Development

Open `index.html` in your browser to view the site. No build steps are required.
